# File Manager Pro (Chrome Extension)
ローカルディレクトリ内のファイルをブラウザ上から直感的かつ安全に一括操作・整理できる Chrome 拡張機能です。  
画面分割作業（Google Colabやエディタ等とのサイドバイサイド表示）に最適化されたレスポンシブUIを備え、日常的なファイル整理・クレンジング作業を大幅に効率化します。

## 🌟 主な特徴

- **安全な一括リネーム機能**
  - **Prefix（接頭辞）の一括追加**: 選択した複数ファイルの先頭に任意の文字列を追加（`+T`）。
  - **Suffix（接尾辞）の一括追加**: 選択した複数ファイルの末尾（拡張子の直前）に任意の文字列を追加（`T+`）。
  - **特定文字列の一括除去**: ファイル名に含まれる不要なタグや特定文字列を一括削除（`T-`、拡張子は自動保護）。
- **誤操作を防ぐ拡張子保護**
  - 単独リネーム時、ダイアログにはベース名のみを表示し、拡張子を誤って削除・変更する事故を防止。
  - テーブル上でも「名前」と「拡張子」を独立した列として分かりやすく表示。
- **一括移動・サブフォルダ管理**
  - 選択した複数のファイルやフォルダを、ダイアログから対象サブフォルダへ一括移動。
- **マルチソート対応**
  - 名前順 / 拡張子順 / サイズ順 / 日時順 の昇順・降順ソートに対応。
  - フルスクリーン時はテーブルヘッダークリック、画面分割時はコンパクトなドロップダウンメニューから切り替え可能。
- **画面分割（狭小幅）に最適化されたレスポンシブUI**
  - 画面幅が狭い場合（860px以下）は、不要な列（拡張子・サイズ・日時）を自動非表示にし、ボタンをアイコン化して一覧性を維持。
  - 削除と混同しやすいゴミ箱アイコンを廃止し、`+T` / `T+` / `T-` による直感的で誤認のないアイコン設計を採用。
- **自動更新（オートリロード）機能**
  - 指定した間隔（3秒〜60秒）でフォルダ内の変更を自動検知して一覧を最新化(初期値は30秒)。
- **独立タブ起動**
  - ツールバーの拡張機能アイコンをクリックすると、ポップアップではなく専用のフルタブとして起動。

## 🚀 インストール手順（開発者モード）

1. 本リポジトリをローカルにクローンまたは ZIP ダウンロードして解凍します。
2. Google Chrome を開き、アドレスバーに chrome://extensions/ を入力して拡張機能管理ページを開きます。
3. 右上の「デベロッパー モード」を有効にします。
4. 左上の「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトのdevフォルダを選択します。
5. ツールバーの拡張機能アイコンから本ツールを起動します（専用タブで開きます）。

## 📖 使い方

1. **フォルダを開く**:
   - 上部の「フォルダを開く」ボタンを押し、整理したい作業ディレクトリを選択してアクセス権を許可します。
2. **新規作成**:
   - パス表示横の「新規ファイル」「新規フォルダ」から即座に新規作成が可能です。
3. **一括リネーム / 移動**:
   - 一覧のチェックボックスで対象ファイルを選択します。
   - 上部ツールバーの入力欄に対象文字列を入力し、「Prefixを追加」「Suffixを追加」または「文字列を除去」を実行します。
   - 「一括移動」を押すとモーダルが開き、移動先のサブフォルダを選択できます。
4. **個別操作**:
   - 行右端のメニューアイコン（≡）から、個別ファイルのリネーム・移動・削除が可能です。

## 🔒 セキュリティとプライバシー

- 本拡張機能は File System Access API を利用し、すべてのファイル操作をユーザーのローカル環境内（クライアントサイド）でのみ実行します。
- 外部サーバーへのファイル送信やトラッキング等の通信は一切行われません。
